# Technical
syschat requires either one of the two implementations of the Common Language Runtime:
1. dotnet runtime (a microsoft product)
2. mono runtime (an open-source implementation)

pick either one and install it before trying to use syschat

run syschat by running the runtime with the executable file as an argument

if you have trouble with the executable files in the releases, you can always compile from source

# Usage
you can create a new message by hitting the enter key then typing a message

send the message by hitting enter again to add the message to the chat log

you can also use a few slash commands by hitting slash, backslash, or by sending a message that starts with either of those

the following slash commands are available:

help: print the help text

front / switch / rp / name / swap: enter a name for a new fronter switching in

dump / log / dumplog: dump the chat log to a file "log.txt" in the working directory

clear: clear the chat history
